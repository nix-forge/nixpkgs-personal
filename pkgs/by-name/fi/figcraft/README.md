# FigCraft

Source build of [FigCraft v0.18.1](https://github.com/storytold/figcraft/releases/tag/v0.18.1), revision `4acc293c2ec941ac1400837ee7e3ab51780399f8`. Installs `figcraft`, `figcraft-cli`, and the headless `figcraft-server` collaboration service. Retains the released editor, CLI automation/MCP, imports/exports, plugins, accessibility, clipboard, and native rendering features. The upstream project is alpha; installation does not establish complete Figma compatibility.

The release deliberately selects craft-fonts `cc9269cd8d8258785dac603fba3122e5d2556795`, which provides both required Latin and common manifests. All 72 licensed fonts are embedded, including the source-supported CJK option. Input hashes and complete installed notices are checked against both manifests. The upstream Linux application discovers configured system fonts through Fontconfig; `FIGCRAFT_NO_SYSTEM_FONTS=1` retains deterministic embedded-only rendering.

The stable release includes ruzstd 0.9.1 for [RUSTSEC-2026-0344](https://github.com/RustSec/advisory-db/blob/main/crates/ruzstd/RUSTSEC-2026-0344.md). Upstream also supplies Rustls 0.23.46 and a native window identifier that matches the Linux desktop file. The package retains strict ZIP header validation for imports, contextual errors when reopening recent files, and embedded fallbacks for the regional fonts in the current font manifests. Restricted corporate assets are omitted from the installed notice collection; the original application icon is explicitly MIT OR Apache-2.0 and retained with its notice.

Linux includes Wayland/X11 and Vulkan/OpenGL runtime libraries, desktop icons, MIME declarations and AppStream metadata. macOS includes the upstream document and `figcraft://` invitation declarations, a source-derived icon and an ad-hoc signature applied after fixup. The command-line binaries remain separately accessible. Browser/WASM deployments and developer xtask are separate upstream targets.

Native builds run workspace library tests, including server tests, with required embedded fonts and bounded Darwin localhost permission. The package verifies the font manifests before compiling and installs source provenance and license notices from the exact font and Git dependency revisions. Cross builds compile without executing target binaries; GUI/compositor, GPU and native-host evidence require separate coordinated validation. No server starts during package installation. Its default listener is `127.0.0.1:47900`, and its data directory is explicitly chosen by the user; see [upstream server documentation](https://github.com/storytold/figcraft/blob/4acc293c2ec941ac1400837ee7e3ab51780399f8/docs/server.md).

The independent recipe supports x86_64/aarch64 Linux and Darwin with Rust 1.95 or newer. Intel Darwin needs a compatible Nixpkgs instance, such as 26.05, because 26.11 dropped that target. Non-NixOS graphics may require [nixGL](https://github.com/nix-community/nixGL) selected from the same Nixpkgs revision.

Updates are manual: review the next stable source, font manifests and asset terms; update `source.nix`, source/font hashes and exact local Cargo.lock; port or remove source patches; then run strict sandbox source, installed metadata/notice, CLI/server and native GUI checks. No unattended updater is supplied for this rapidly changing alpha application.

See the [patch-retirement record](../../../../docs/research/artcraft-patch-retirement-research.md) for earlier releases. Earlier completed build receipts apply only to their recorded revisions.
