# Support

Start with the repository [README](README.md), package metadata, and the
upstream project named by the package. This repository does not replace an
upstream project's documentation or support channel.

For a packaging bug or a reproducible flake problem, [open an issue](https://github.com/nix-forge/nixpkgs-personal/issues/new).
Include the package name, commit or input revision, target system, expected and
actual behavior, and the smallest useful log excerpt. Remove secrets and
private paths before posting.

Use [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Do not disclose
security-sensitive details in a public issue.

This project does not provide managed package builds or private deployment
support. Public, minimal reproductions help keep the package catalog useful to
other consumers.
